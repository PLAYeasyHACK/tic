# Git e GitHub para Iniciantes

## Objetivo
nenhum
## Público-alvo
Estudantes sem experiência prévia em controle de versão, que querem aprender a usar Git e GitHub do zero.

## Pré-requisitos
- Terminal básico (navegar entre pastas, executar comandos)
- Conta no GitHub
- Git instalado na máquina

## Estrutura do guia
- docs/01-introducao.md
- docs/02-conceitos.md
- docs/03-exercicios.md
- docs/04-referencias.md

## Como navegar
Comece por docs/01-introducao.md e siga a ordem numérica dos arquivos. Os exercícios em 03-exercicios.md acompanham os conceitos apresentados em 02-conceitos.md.
